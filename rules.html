Домашняя работа — CSS Grid и Selectors

Правила выполнения домашней работы

Перед началом внимательно ознакомься со всеми правилами. В этой работе важно не просто повторить макет, а научиться самостоятельно подбирать нужные CSS-селекторы и правильно строить сетки через Grid.

Общие правила

Все иконки должны храниться в отдельном SVG-файле и подключаться в HTML через тег use.
Все размеры, отступы, цвета, границы и другие свойства необходимо брать через DevTools.
Не копируй стили вслепую. Главная задача — понять, почему используется конкретный подход.
В некоторых секциях требуется применять стили только через определённые виды селекторов.

Секция 01 — Grid Columns

  • Для первого блока используй селектор, который находит класс по окончанию его названия.
  • Для второго блока используй селектор, который ищет совпадение по началу названия класса.
  • Для третьего блока используй селектор, который ищет отдельное слово внутри списка классов.
  • Для четвёртого блока используй селектор, который ищет часть фразы внутри названия класса.

Секция 02 — Grid Columns & Rows

  • Стили для большой картинки нужно применить через селектор, который ориентируется на окончание названия класса.
  • Стили для маленьких карточек также применить через селектор, работающий с окончанием класса.
  • При построении сетки использовать одновременно grid-template-columns и grid-template-rows.

Секция 03 — Grid Lines

  • Построение секции выполнять через линии Grid.
  • Для размещения блоков использовать: grid-column и grid-row.
  • Следи за тем, какие элементы занимают несколько колонок или строк.

Секция 04 — Grid Template Areas

  • Построение выполнять через шаблон областей Grid.
  • Для размещения элементов использовать именованные области.
  • Стили дочерним элементам применять через селектор, который работает только с прямыми потомками.

Секция 05 — CSS Selectors

Для первого блока применить стили ко всем прямым дочерним элементам.
Во втором блоке стилизовать первые две ссылки через атрибут, отвечающий за открытие ссылки в новой вкладке.
Для ссылки «Контакты» использовать селектор, который работает с частью имени класса до символа разделителя
(except—).
В третьем блоке объединить несколько селекторов через запятую, чтобы задать общие стили сразу нескольким элементам.
Для последней кнопки взаимодействие через hover выполнять через селектор атрибута с конкретным значением типа.
В четвёртом блоке применить одинаковые стили ко всем внутренним тегам.
В пятом блоке изменить цвет только первому дочернему элементу.
В шестом блоке изменить цвет только последнему дочернему элементу.
В седьмом блоке обратиться к конкретному элементу по его порядковому номеру.
В восьмом блоке:
  • Сначала задать общий фон всем карточкам.
  • Затем отдельно изменить фон первой карточки.
  • После этого через специальный селектор соседнего элемента изменить фон следующей карточки.
  • И в конце — через исключающий селектор выбрать только нужный блок, исключив первый, последний и второй элементы.
Важно: цель этой домашней работы — научиться самостоятельно определять, какой именно селектор нужен в конкретной ситуации, а не просто переписывать готовый код.
