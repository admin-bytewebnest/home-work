Разбираемся с :has()

15 практических задач, чтобы научиться выбирать элементы по их содержимому и состоянию. Выполняй задания по порядку и проверяй себя на интерактивных примерах.

Примеры работают в браузере HTML + CSS

01
ТВОЯ ЗАДАЧА

Выдели карточку, внутри которой есть ссылка с атрибутом target="_blank". Только такая карточка должна получить акцентную рамку.

Показать подсказку
.demo-card:has(a[target="_blank"])

Проверь наличие ссылки с нужным значением атрибута target внутри карточки.

Результат
Внешняя страницаОткрыть сайт ↗

ТВОЯ ЗАДАЧА

Измени оформление строки, если переключатель внутри неё включён.

Показать подсказку
.setting:has(input:checked)

Псевдокласс :checked выбирает отмеченный checkbox или radio внутри строки.

Результат
03
ТВОЯ ЗАДАЧА

Подсвети всю форму, когда любое поле ввода находится в фокусе.

Показать подсказку
.search-form:has(input:focus)

Псевдокласс :focus срабатывает, пока поле ввода находится в фокусе.

Результат
При фокусе на поле подсвечивается весь блок.
04
ТВОЯ ЗАДАЧА

Покажи успешное состояние карточки, когда введён корректный адрес электронной почты.

Показать подсказку
.field-card:has(input:valid)

Псевдокласс :valid выбирает поле, которое проходит встроенную HTML-валидацию.

Результат
Например: hello@example.com
05
ТВОЯ ЗАДАЧА

Выдели карточку, если адрес электронной почты введён некорректно или обязательное поле оставлено пустым.

Показать подсказку
.field-card:has(input:invalid)

Псевдокласс :invalid выбирает поле, которое не проходит встроенную HTML-валидацию.

Результат
Поле обязательно для заполнения.

ТВОЯ ЗАДАЧА

Выдели товар, если он одновременно отмечен как доступный и содержит кнопку покупки.

Показать подсказку
.product:has(.stock):has(button)

Поставь два :has() подряд: первый проверяет наличие .stock, второй — button. Оба условия обязательны.

ТВОЯ ЗАДАЧА

Измени оформление текста-подсказки, если переключатель согласия включён.

Показать подсказку
.consent:has(input:checked) .hint

Сначала найди .consent с отмеченным input, а затем выбери .hint внутри этого контейнера.

Результат

После согласия эта подсказка меняет цвет.

У этого блока состояние уже активно.

ТВОЯ ЗАДАЧА

Выдели карточки с изображением, кроме тех, которые отмечены как отсутствующие в продаже.

Показать подсказку
.item:has(img):not(:has(.sold-out))

Проверь наличие img и исключи карточки, внутри которых есть .sold-out.

ТВОЯ ЗАДАЧА

Найди блок, в котором есть заголовок, но нет описания.

Показать подсказку

Через :not(:has()) исключи блоки с .description, а через :has() проверь наличие h4.

ТВОЯ ЗАДАЧА

Выдели список, если в нём остался хотя бы один невыполненный пункт.

Показать подсказку

Внутри :has() найди .todo-item, у которого отсутствует класс .done.

ТВОЯ ЗАДАЧА

Выдели панель, в которой есть заголовок.

Показать подсказку
.panel:has(:is(h2, h3, h4))

Используй :is() для объединения h2, h3 и h4 внутри проверки :has().

Результат

ТВОЯ ЗАДАЧА

Измени оформление абзаца, который расположен сразу после карточки с заголовком.

Показать подсказку
.story:has(:is(h3, h4, h5)) + p

Найди .story с одним из заголовков через :is(), затем выбери следующий соседний абзац с помощью +.
